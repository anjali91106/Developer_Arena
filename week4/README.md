# TechHub - Technology News & Insights Website

A modern, responsive blog/news website built with HTML5, CSS3, and vanilla JavaScript. This project demonstrates professional web development practices with semantic HTML, responsive design, and interactive features.

## 🎯 Project Overview

TechHub is a comprehensive technology news and insights platform that features:
- Latest technology articles and news
- Responsive design for all devices
- Interactive category filtering
- Contact form with validation
- Newsletter subscription
- Search functionality
- FAQ section
- Team showcase
- Services presentation
